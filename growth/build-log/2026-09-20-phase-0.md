## COMPLETED — Draft recovery and writing-safe saves

Session startup now loads document contents and unsaved backups before publishing
tabs. Restored drafts keep dirty state and cursor positions. Each untitled draft
has its own backup identity, and backup revisions include content in their keys.
Writes are serialized and the session JSON is replaced atomically after backups
succeed. Invalid or unsupported sessions and missing unsaved backups pause session
writes to preserve the prior recovery data. Legacy backup keys remain readable.

Normal document saves preserve trailing spaces (including Markdown hard breaks)
and leave edits made during a pending write dirty. Dirty-close saves can use an
unmounted recovered buffer; failed saves keep the tab open. Stable tab IDs prevent
first-edit dirty updates from remounting the writing surface and interrupting
keyboard input.

Desktop testing exposed fractional sidebar widths being rejected by Rust's
integer session field. Persistence now rounds/clamps that value. Session save
failures also appear in the app console. Fixed the native macOS menu hierarchy so
File remains a separate menu, and replaced the remaining IDE welcome subtitle.

## Remaining Phase 0 task — Reliable terminal scrollback

The terminal-preservation checklist item stays open. A burst of 100 output lines
left only the visible screen searchable; earlier output was missing from the
frontend scrollback. Reproduce in a terminal with:

```sh
for i in {1..100}; do echo BUSTERMARK_LINE_$i; done
```

Cmd+F → `BUSTERMARK_LINE_1` found only the visible `..._100` match instead of all
12 expected matches (1, 10–19, 100). Inspection shows the inherited frontend
captures only a one-row shift between screen deltas. A native scrollback/delta
contract is needed to preserve rows when multiple lines arrive together; do not
mark the remaining task completed based solely on the search UI repair.
